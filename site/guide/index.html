ChadScanner guide

ChadScanner is a free Windows app for Escape from Tarkov. Shift + click an item in your stash and a card next to the cursor shows how many you still need for quests and hideout upgrades and what the item sells for. It reads the screen with screenshots and OCR only. This guide covers install, the card, hotkeys, progress sync and fixes.

How to install ChadScanner

  1. Download chadscanner-win-x64.zip. On the Releases page it is the file labelled chadscanner-win-x64.zip; ignore the other files.
  2. Right-click the zip → Extract All… and choose a place you own, e.g. C:\; this creates C:\ChadScanner. Not Program Files (updates rewrite this folder), and don't run it from inside the zip.
  3. Open the ChadScanner folder and double-click chadscanner.exe. SmartScreen warns about an unsigned app: More info → Run anyway. The first start downloads the item data (about 180 MB); a toast says when it is done.
  4. In EFT set Borderless (Settings → Graphics → Screen mode). Exclusive fullscreen is not supported: the card is a normal topmost window and cannot be drawn over an exclusive-fullscreen game.
  5. Shift + Left-click an item in your stash. ChadScanner sits in the tray; right-click it for Settings, Pause scanning, Check for updates and Quit.

How to read the item card

Example card for the item NaCl:

NaCl                                   27× needed
QUESTS
4×  Pets Won't Need It                  FIR · now
3×  First in Line            FIR · trader dialogue
3×  Thirsty - Secrets                FIR · 4 quests
HIDEOUT
6×  Medstation 2                              now
10× Medstation 3                       3 upgrades
──────────────────────────────────────────────────
Flea 94 666 ₽                   Therapist 4 339 ₽
Barters 3 · Crafts 5

The border colour tells you what to do with the item:

Border Meaning What to do
Amber Needed now by a quest or hideout upgrade you can do now Keep it
Purple Kappa quest Keep it
Brown Needed later Keep it
Grey Not needed, or low value Sell it
Green Not needed, worth at least 30 000 ₽ per slot Flea it
  • n× needed: everything still needed, after what you have already handed in or marked.
  • Rows: one per quest or hideout level. The right side says how far away it is: now, 2 quests, 3 upgrades, Lv 30, trader level, trader dialogue, story step. FIR means the item must be found in raid; last item means everything else for that quest or upgrade is already done.
  • Smart ordering (default) lists the closest first: now, then fewest quests, upgrades or levels away.
  • Goal Kappa or Lightkeeper moves other quests to the bottom, labelled "NOT KAPPA".
  • Prices: Flea is the 24-hour average flea market price. The right side is the best trader sell price and that trader.

Scan buttons

The default scan button is Shift + Left click. Other options: Alt + Left, Middle, Mouse 4 and Mouse 5. Change it under Settings → Scanning.

Hand in quest items with Arrow Up

With EFT focused, Arrow Up adds one to the first need on the last scanned item's card that still has room (quests, then hideout; each nearest first) and redraws the card. Arrow Down undoes the last one. With Scanning → Arrow Up also fills non-FIR needs off, an item with any FIR need only fills its FIR ones. The keys still reach the game. Switch them off under Scanning.

With TarkovTracker as the source a change shows on the card at once and is confirmed with a read 30 seconds after the last write. If the server does not report what was written, the server's value wins and the disagreement is logged and shown as a toast.

Progress: on this PC or TarkovTracker

  • On this PC: %APPDATA%\ChadScanner\progress.json in TarkovTracker backup format, so it can be imported at tarkovtracker.org. Tasks you finish are filled in from EFT's logs, including ones finished while the app was closed. EFT does not log hideout upgrades: set them on the Hideout page.
  • TarkovTracker.org: reads your progress every 5 minutes, and on a scan when it is older than 60 seconds (within the free 1000 reads per day), and writes completed and failed tasks from the logs. Items you mark on its needed-items page lower the counts on the card. Its API cannot change the hideout.

The game mode switches between PvP and PvE by itself when EFT starts a session.

Built-in TarkovTracker window

A second window, ChadScanner · TarkovTracker, embeds tarkovtracker.org (WebView2) so no separate browser is needed. It opens at start; closing it hides it, and the tray item TarkovTracker brings it back. Log in once (Discord, GitHub, Twitch or email; Google may be refused inside WebView2); the login is kept. The site must be set to English.

  • A scan opens the item's Needed-Items view in the window.
  • While the window is open and EFT is focused, Arrow Up / Down change one quest objective or hideout part count on the site (the first need on the card with room; no Smart Fill) instead of the quest-progress keys above. Counts stay identical on both sides; the site's popup lists rows in its own order, and pressing Smart Fill there moves counts between rows (the card follows). With the window closed the keys work as described above, for quest objectives only.
  • The card redraws after every press from the window's own progress (same game mode only); the next API read confirms it.

Settings

Right-click the tray icon → Settings. Changes are saved and applied immediately.

Page What it sets
Card Sections (quests, hideout, barters, crafts), non-FIR needs, rows, Smart / Simple order, Goal, size, close when the mouse leaves, timeout
Progress Where progress is kept: On this PC (local file) or TarkovTracker.org (API tokens per game mode, with Test); player level and faction; import a TarkovTracker backup
Hideout Built station levels (local progress only)
Scanning Scan button: Shift + Left, Alt + Left, Middle, Mouse 4, Mouse 5; quest progress keys and non-FIR fill
EFT logs Quest tracking on/off, logs folder
About Log file, settings folder, debug reports

Updates

The app checks GitHub 30 seconds after start and every 6 hours. A newer release shows a toast and the tray item becomes Update to vX.Y.Z; clicking it downloads, swaps the files and restarts. Item data is downloaded again only when it changed. Check for updates in the tray menu checks on demand.

Troubleshooting

  • The card doesn't show up → set EFT to Borderless.
  • It scanned the wrong item → press Ctrl + Shift + F12 right after a scan that went wrong. It saves %APPDATA%\ChadScanner\reports\report-<time>\ with the scan's screenshot, the candidates with scores and why the scan was accepted or rejected (report.json), the screen at that moment and the log tail. Attach it to a GitHub issue.
  • "Item data download failed" → check the internet connection and restart ChadScanner; details are in %APPDATA%\ChadScanner\log.txt.
  • SmartScreen warns about an unsigned app → More info → Run anyway.
  • Uninstall → Quit from the tray, then delete the install folder and %APPDATA%\ChadScanner.

Where ChadScanner keeps its files

Where What
C:\ChadScanner\ chadscanner.exe, onnxruntime.dll, data\ (models, index, item images)
%APPDATA%\ChadScanner\ config.json, progress.json, pending.json (TarkovTracker writes waiting for retry), logstate.json (EFT log read position), tracker-window.json (TarkovTracker window position), webview\ (its browser profile: keeps the login), cache\ (tarkov.dev data), reports\, log.txt

Where the data comes from

  • Items, quests, hideout, traders, barters, crafts: json.tarkov.dev, refreshed every 10 minutes.
  • Quests only TarkovTracker adds (e.g. "Pay the Fare!"): its tasks-core endpoint, merged in when json.tarkov.dev lacks them.
  • Progress: the TarkovTracker API or the local file.
  • Quest events and game mode: EFT's own log files.
