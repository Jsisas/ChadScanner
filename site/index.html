What is ChadScanner?

ChadScanner is a free Windows app for Escape from Tarkov (EFT) that shows item info as a large floating card. Shift + click an item in your stash and the card lists how many of it you still need for quests and hideout upgrades, whether a Kappa quest wants it, and what it sells for on the flea market and to traders.

Platform
Windows 10/11 x64. EFT in Borderless mode.
Price
Free. No account, no ads.
How it reads items
Screenshot around the cursor, image recognition and OCR (ChadVision). No memory reading, no injection.
Data
Items, quests, hideout, prices, barters and crafts from tarkov.dev, refreshed every 10 minutes.
Progress
A local file on your PC or synced with TarkovTracker.org.
Game modes
PvP and PvE, switched automatically from EFT's logs.
In raid
TarkovTracker's map of the location with your own extracts, opened at spawn.

Zero ban risk. It only looks at your screen.

ChadScanner takes screenshots of your screen (around the cursor, EFT's menus and exfil panel) and reads them with image recognition and OCR — the same pixels your eyes already see. It never reads or writes game memory, never injects anything, never touches game files. OCR is not against Battlestate Games' rules. Don't trust us — read the code. Every line is open for anyone to inspect.

Four steps to Chad status

  1. Download & extract

    Click Download. You get chadscanner-win-x64.zip. Right-click it → Extract All… and pick a place you own, like C:\; that creates C:\ChadScanner. Not Program Files — updates rewrite that folder. Don't run it from inside the zip.

  2. Run it

    Open the ChadScanner folder and start chadscanner.exe. SmartScreen whines about an unsigned app: More info → Run anyway. First start downloads the item data (~180 MB).

  3. Go borderless

    In EFT: Settings → Graphics → Screen mode → Borderless. Exclusive fullscreen can't show the card.

  4. Shift + click

    ChadScanner lives in the tray. Right-click it for Settings, Pause scanning and Check for updates. Now go loot.

FAQ: questions from the virgins

Will I get banned for using ChadScanner?

No. ChadScanner only takes screenshots and runs OCR on them. No memory reading, no injection, no game-file changes, and OCR is not against Battlestate Games' rules. The full source of ChadScanner and ChadVision is on GitHub for anyone to inspect.

Is ChadScanner free?

Yes. Free, open source, no account, no ads.

Why doesn't the card show up in game?

Set EFT to Borderless. The card is a normal topmost window and can't draw over exclusive fullscreen.

What if it scanned the wrong item?

Press Ctrl + Shift + F12 right after the bad scan. It saves a debug report with the screenshot and the candidates to %APPDATA%\ChadScanner\reports\ — attach it to a GitHub issue.

Do I need TarkovTracker?

No. Progress can live in a local file on your PC. Connect TarkovTracker.org with an API token if you want it synced, or import a TarkovTracker backup.

Does it work in PvE?

Yes. ChadScanner reads EFT's logs and switches between PvP and PvE by itself when a session starts. With TarkovTracker, set an API token for each game mode.

Which prices does the card show?

Flea is the 24-hour average flea market price from tarkov.dev. The right side is the best price a trader pays and that trader's name. The border turns green when an item is worth at least 30 000 ₽ per slot.

Where does the price and quest data come from?

Items, quests, hideout, traders, barters and crafts from tarkov.dev, refreshed every 10 minutes. Quest events and game mode from EFT's own logs.

Why does SmartScreen or antivirus warn about it?

The exe isn't code-signed. Click More info → Run anyway. The source is public if you want to check it yourself.
