Four steps to Chad status

  1. Download & extract

    Get the zip from Releases and extract it to a folder you own, like C:\ChadScanner. Not Program Files — updates rewrite that folder.

  2. Run it

    Start chadscanner.exe. SmartScreen whines about an unsigned app: More info → Run anyway. First start downloads the item data (~180 MB).

  3. Go borderless

    In EFT: Settings → Graphics → Screen mode → Borderless. Exclusive fullscreen can't show the card.

  4. Shift + click

    ChadScanner lives in the tray. Right-click it for Settings, Pause scanning and Check for updates. Now go loot.

Questions from the virgins

Will I get banned?

No. ChadScanner only takes screenshots and runs OCR on them. No memory reading, no injection, no game-file changes, and OCR is not against Battlestate Games' rules. The full source of ChadScanner and ChadVision is on GitHub for anyone to inspect.

Is it free?

Yes. Free, open source, no account, no ads.

The card doesn't show up in game.

Set EFT to Borderless. The card is a normal topmost window and can't draw over exclusive fullscreen.

It scanned the wrong item.

Press Ctrl + Shift + F12 right after the bad scan. It saves a debug report with the screenshot and the candidates to %APPDATA%\ChadScanner\reports\ — attach it to a GitHub issue.

Do I need TarkovTracker?

No. Progress can live in a local file on your PC. Connect TarkovTracker.org with an API token if you want it synced, or import a TarkovTracker backup.

Where does the data come from?

Items, quests, hideout, traders, barters and crafts from tarkov.dev, refreshed every 10 minutes. Quest events and game mode from EFT's own logs.

SmartScreen / antivirus warning?

The exe isn't code-signed. Click More info → Run anyway. The source is public if you want to check it yourself.
